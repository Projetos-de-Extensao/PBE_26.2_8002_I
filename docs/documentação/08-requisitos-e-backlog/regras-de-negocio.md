# Regras de Negócio

| ID | Regra |
|---|---|
| RN01 | Um profissional não pode possuir dois atendimentos simultâneos. |
| RN02 | Um cliente não pode possuir dois atendimentos simultâneos. |
| RN03 | Uma sala não pode ser reservada por dois atendimentos no mesmo intervalo. |
| RN04 | Um recurso exclusivo não pode ser reservado simultaneamente. |
| RN05 | Apenas horários marcados como disponíveis podem ser selecionados. |
| RN06 | Um agendamento deve estar associado a um cliente, profissional e serviço. |
| RN07 | A duração do agendamento deve considerar a duração definida para o serviço. |
| RN08 | Um profissional só pode visualizar informações permitidas pelo seu perfil. |
| RN09 | O administrador possui permissão de gestão global da organização. |
| RN10 | Cancelamentos devem atualizar imediatamente a disponibilidade do horário. |
| RN11 | Em uma recorrência, cada ocorrência deve ser validada individualmente contra conflitos. |
| RN12 | Se uma ocorrência recorrente conflitar, o sistema deve informar o usuário e não sobrescrever outra reserva. |
