# Requisitos Funcionais

| ID | Requisito |
|---|---|
| RF01 | O sistema deve permitir cadastro de usuários. |
| RF02 | O sistema deve permitir autenticação por e-mail e senha. |
| RF03 | O sistema deve permitir recuperação de senha. |
| RF04 | O administrador deve cadastrar profissionais. |
| RF05 | O administrador deve cadastrar serviços. |
| RF06 | O administrador deve cadastrar salas e recursos. |
| RF07 | O profissional deve configurar sua disponibilidade. |
| RF08 | O cliente deve pesquisar profissionais. |
| RF09 | O cliente deve visualizar horários disponíveis. |
| RF10 | O cliente deve realizar agendamentos. |
| RF11 | O cliente deve cancelar agendamentos. |
| RF12 | O cliente deve reagendar atendimentos. |
| RF13 | O sistema deve impedir conflito de horário do profissional. |
| RF14 | O sistema deve impedir conflito de horário do cliente. |
| RF15 | O sistema deve impedir conflito de sala ou recurso. |
| RF16 | O sistema deve permitir agendamentos recorrentes. |
| RF17 | O sistema deve exibir agenda do cliente. |
| RF18 | O sistema deve exibir agenda do profissional. |
| RF19 | O sistema deve controlar permissões conforme o perfil. |
| RF20 | O sistema deve permitir bloqueio manual de horários. |
| RF21 | O sistema deve enviar lembretes de atendimento. |
| RF22 | O sistema deve permitir lista de espera. |
| RF23 | O administrador deve consultar dados operacionais básicos. |
| RF24 | O sistema deve registrar status do atendimento. |
