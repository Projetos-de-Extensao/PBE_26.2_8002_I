# Requisitos Não Funcionais

| ID | Requisito |
|---|---|
| RNF01 | A interface deve ser responsiva para desktop, tablet e celular. |
| RNF02 | As principais páginas devem possuir navegação simples e consistente. |
| RNF03 | Senhas não devem ser armazenadas em texto puro. |
| RNF04 | O acesso deve respeitar autenticação e autorização. |
| RNF05 | O banco de dados deve manter integridade entre usuários, profissionais, horários e recursos. |
| RNF06 | O sistema deve validar conflitos antes de confirmar um agendamento. |
| RNF07 | O código deve ser versionado com Git. |
| RNF08 | A aplicação deve possuir organização modular para facilitar manutenção. |
| RNF09 | Erros devem apresentar mensagens compreensíveis ao usuário. |
| RNF10 | Dados sensíveis devem ter acesso restrito aos perfis autorizados. |
