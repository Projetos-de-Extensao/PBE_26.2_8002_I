# Histórias de Usuário

## Cliente
**HU01** — Como cliente, quero criar uma conta para utilizar a plataforma.

**HU02** — Como cliente, quero pesquisar profissionais por especialidade para encontrar o atendimento adequado.

**HU03** — Como cliente, quero ver horários disponíveis para escolher o melhor momento.

**HU04** — Como cliente, quero agendar um atendimento para reservar meu horário.

**HU05** — Como cliente, quero reagendar ou cancelar um atendimento quando meus planos mudarem.

**HU06** — Como cliente, quero visualizar todos os meus atendimentos em uma agenda única.

## Profissional
**HU07** — Como profissional, quero definir minha disponibilidade para controlar quando posso receber clientes.

**HU08** — Como profissional, quero visualizar minha agenda para planejar meu dia.

**HU09** — Como profissional, quero bloquear horários específicos para impedir novos agendamentos.

**HU10** — Como profissional, quero criar sessões recorrentes para clientes que possuem rotina fixa.

## Recepcionista
**HU11** — Como recepcionista, quero localizar um cliente e agendar em seu nome para prestar atendimento presencial ou por telefone.

**HU12** — Como recepcionista, quero consultar disponibilidade de profissionais e salas para evitar conflitos.

## Administrador
**HU13** — Como administrador, quero cadastrar profissionais e serviços para configurar a plataforma.

**HU14** — Como administrador, quero cadastrar espaços e recursos para controlar a estrutura física.

**HU15** — Como administrador, quero definir papéis e permissões para limitar o acesso às funções.
