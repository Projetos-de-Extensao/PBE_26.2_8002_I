# 5W2H

| Elemento | Definição |
|---|---|
| **What — O quê?** | Desenvolver uma plataforma web de agendamento multidisciplinar para personal trainers, nutricionistas, fisioterapeutas e outros profissionais. |
| **Why — Por quê?** | Centralizar agendas, reduzir conflitos, facilitar a comunicação e melhorar a organização dos atendimentos. |
| **Where — Onde?** | Em navegador web, com interface responsiva para computador, tablet e celular. |
| **When — Quando?** | Implementação por etapas: MVP, automações, recursos avançados e futuras integrações. |
| **Who — Quem?** | Clientes, profissionais, recepcionistas e administradores. |
| **How — Como?** | Front-end em React, API em Node.js/Express, banco PostgreSQL e controle de acesso por papéis. |
| **How much — Quanto?** | MVP acadêmico pode utilizar serviços gratuitos; custos maiores só seriam necessários em produção. |

## Plano por etapas

### Etapa 1 — MVP
- login;
- cadastro;
- profissionais;
- serviços;
- disponibilidade;
- agendamento;
- cancelamento;
- agenda.

### Etapa 2 — Operação
- espaços;
- recursos;
- recorrência;
- conflitos;
- permissões.

### Etapa 3 — Automação
- notificações;
- lista de espera;
- lembretes;
- dashboard.

### Etapa 4 — Evolução
- pagamentos;
- relatórios;
- aplicativo mobile;
- integrações externas.
