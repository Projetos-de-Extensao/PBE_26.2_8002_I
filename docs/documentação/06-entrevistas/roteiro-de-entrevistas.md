# Entrevistas — Roteiro e Planejamento

> Não registrar respostas fictícias como se fossem entrevistas reais. Use este documento como roteiro e preencha depois com pessoas entrevistadas.

## Objetivo
Validar se clientes e profissionais realmente enfrentam problemas de organização, conflitos de horário, recorrência e uso de múltiplas ferramentas.

## Perfil 1 — Cliente
Perguntas:
1. Você faz acompanhamento com personal, nutricionista, fisioterapeuta ou outro profissional?
2. Como marca seus horários atualmente?
3. Já esqueceu um atendimento ou teve conflito de agenda?
4. Usa WhatsApp, agenda do celular ou outro aplicativo para organizar isso?
5. Gostaria de visualizar todos os profissionais em uma única agenda?
6. A recorrência semanal seria útil?
7. Gostaria de receber lembretes?
8. Em um cancelamento, teria interesse em lista de espera?
9. Qual informação gostaria de ver antes de escolher um profissional?
10. O que faria você usar ou não usar essa plataforma?

## Perfil 2 — Profissional
Perguntas:
1. Como você organiza sua agenda?
2. Quantos clientes atende aproximadamente por semana?
3. Você possui horários recorrentes?
4. Já teve choque de horários?
5. Como comunica cancelamentos e mudanças?
6. Usa sala ou equipamento que também é compartilhado?
7. Seria útil bloquear horários e recursos pelo sistema?
8. Quais dados de um cliente você precisa visualizar?
9. Que relatório seria útil?
10. Qual seria a principal razão para adotar o sistema?

## Perfil 3 — Recepcionista/Gestor
Perguntas:
1. Como os atendimentos são marcados hoje?
2. Quantos profissionais compartilham a mesma agenda/estrutura?
3. Existem conflitos de salas ou equipamentos?
4. Como são controlados cancelamentos e faltas?
5. Como funcionam sessões recorrentes?
6. Quais informações precisam ficar restritas?
7. Quais relatórios são necessários?
8. Existe lista de espera?
9. Quais tarefas mais consomem tempo?
10. Qual problema o sistema deveria resolver primeiro?

## Hipóteses a validar
- H1: usuários têm dificuldade para coordenar múltiplos profissionais.
- H2: recorrência economiza tempo para profissionais.
- H3: conflitos de espaços são relevantes para estabelecimentos.
- H4: lembretes diminuem esquecimentos.
- H5: uma agenda unificada agrega valor para clientes.
