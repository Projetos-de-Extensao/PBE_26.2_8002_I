## Visão rápida

A solução centraliza:
- agendamento com diferentes tipos de profissionais;
- agenda do cliente e do profissional;
- gestão de salas, espaços e recursos;
- recorrência de sessões;
- prevenção de conflitos de horário;
- perfis e privilégios de acesso;
- lembretes e notificações;
- lista de espera;
- histórico de atendimentos.

## Perfis previstos
- Cliente
- Profissional
- Recepcionista
- Administrador

## Tecnologias sugeridas para o MVP
- Front-end: React
- Back-end: Node.js + Express
- Banco de dados: PostgreSQL
- Autenticação: JWT ou serviço equivalente
- Versionamento: Git + GitHub
